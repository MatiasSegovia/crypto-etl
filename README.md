## 📖 Description

Crypto-ETL is a modular ETL pipeline that consumes data from a public API, transforms, validates, and exports it to CSV and Excel files ready for analysis. The architecture separates each stage of the process (Extract, Transform, Validate, and Load), uses external configuration via `config.json`, logs execution with an integrated logging system, and handles errors in a centralized manner to facilitate maintenance and scalability.

## ⚡ Features

✅ **Modular Architecture** (Extract, Transform, Validate, Load) — strict separation of responsibilities  
✅ **External Configuration** via `config.json` — zero *hardcoding*  
✅ **Automatic Data Validation** — verifies integrity, types, and ranges before exporting  
✅ **Centralized Error Handling** — robust exception capture and reporting system  
✅ **Integrated Logging System** — complete execution traceability  
✅ **Multi-Format Export** (CSV and Excel) — ready for immediate analysis

- **Language:** Python 3.x

- **Data Processing:** Pandas

# 🚀How to Run
Follow the steps below to run the ETL pipeline locally:

## 1. Clone the repository
````
git clone https://github.com/MatiasSegovia/crypto-etl.git
cd crypto-etl
````

## 2. (Optional) Create a virtual environment
python -m venv venv
### On Windows:
venv\Scripts\activate
### On Mac/Linux:
source venv/bin/activate

## 3. Install dependencies
````bash
pip install -r requirements.txt
````
## 4. Configure parameters
Edit config.json to define the cryptocurrency, reference currency, and number of days you want to query.

## 5. Run the pipeline
````
python src/main.py
````
